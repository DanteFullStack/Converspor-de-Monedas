💱 Conversor de Monedas en Java

Este proyecto es un reto de programación de Alura Latam, desarrollado como parte de mi formación como estudiante de Java Backend.

La aplicación es un conversor de monedas por consola, que permite convertir valores entre distintas divisas utilizando una API externa de tasas de cambio en tiempo real.

🚀 Funcionalidades

Menú interactivo por consola

Conversión entre diferentes monedas

Consumo de una API externa

Manejo de errores con try-catch

Uso de DTO para mapear la respuesta de la API

Estructura del proyecto organizada por paquetes

🛠️ Tecnologías y conceptos utilizados

Java

HttpClient para realizar peticiones HTTP

Gson para el manejo de JSON

API externa de conversión de monedas

Excepciones (try-catch)

Programación orientada a objetos

Buenas prácticas de organización de código

📁 Estructura del proyecto
com.alura.conversormonedas

├── principal   → Lógica principal y menú
├── servicio    → Consumo de la API
